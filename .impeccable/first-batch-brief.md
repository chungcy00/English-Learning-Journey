# First implementation batch

Mode: Operate / Read. Scope: shared palette, HomeView, ReadingHistoryView, saved reading level distribution.

## Direction contract
THESIS: A compact learning workspace, not a marketing page. Keep the current learning flow and confirmed type sizes.
OWN-WORLD: Warm white paper, forest green actions, green-gray supporting text. Rounded input and settings surfaces; pill choices and accessible focus states.
STORY: Enter a topic, adjust all visible parameters, generate, and return to actual saved readings. The chart describes readings, never ability.
FIRST VIEWPORT: Existing navigation and compact heading; integrated composer and submit action; suggestions below; expanded segmented CEFR controls and parameter rows. History shows factual cards and a labeled level chart.
FORM: User-pinned references and confirmed requirements; code-first approved by the user. No new concept selection. Stepper boundaries and pressed button states are the signature interaction; no entrance animation.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
