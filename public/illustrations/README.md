# Mine English learning companions

`learning-companions.webp` is the shared transparent 4 × 4 atlas. It is generated with the built-in imagegen tool from the user-provided `03-角色与组件规范.png`; the source art establishes character identity. No external stock, new fonts or icon libraries are used. The 16 equal cells in the 1254 × 1254 atlas are addressed by `src/components/LearningArt.tsx`.

Rows: cat welcome / reading / thinking / success; cat reminder / rest / peek / shared-reading logo; hamster welcome / reading / thinking / success; hamster reminder / rest / peek / leafy sprig. Blank signs intentionally carry no baked-in UI text. All UI copy remains selectable HTML.

Use `Mascot` for decorative artwork, `Companion` for edge placement and `StudyEmptyState` for accessible text beside small artwork. Every sprite is aria-hidden, non-interactive and given a reserved aspect ratio. Do not create separate page-specific versions of these characters. Reduced-motion styles stop the waiting animation.

Exact generation prompt:

Edit the supplied character style guide into a production transparent sprite atlas for the Mine English website. Preserve the exact cream-white chubby cat with triangular ears, round golden hamster with round ears, small dark eyes, pink warm cheeks and organic delicate hand-drawn outline from the source; do not redesign either character. Remove ALL original UI, text, labels, grids, frames and backgrounds. Output one square image with a strict invisible 4-column by 4-row equal-size grid, 16 centered isolated illustrations, each fully inside its cell with 15% empty margin on all sides. No visible grid, no labels, no text anywhere. Row1: cat waving welcome; cat reading a forest-green book; cat thinking; cat celebrating. Row2: cat holding a blank reminder sign; cat resting curled up; cat peeking over a thin imaginary horizontal edge paws visible (no actual edge); cat and hamster sitting together reading ONE shared forest-green book as compact brand logo. Row3: hamster waving welcome; hamster reading forest-green book; hamster thinking; hamster celebrating. Row4: hamster holding a blank reminder sign; hamster resting curled up; hamster peeking paws visible no edge; one small curved sage-green leafy sprig with five leaves. All figures in exactly consistent source art style. Flat subtle hand coloring, no scene, no drop shadows outside figures, clean truly transparent background. Palette constrained to website: cream #FDFDFC and #F8F7F2, golden #EBCB9E #D8B66A, green #315E4C #98A78C #B1BBA3, outlines #20251F. Preserve source delicate warmth, not vector geometric icons. Make atlas suitable for CSS 400% sprite positioning; strict cell placement important.

Delivery uses WebP with native alpha (approximately 340 KiB for the shared atlas). PNG authoring originals remain in the generator output directory, outside the shipped application.

Five registered 12-frame animation sheets live under `loading/`: run (1.2 s), read (2.8 s), write (2.6 s), search (2.6 s), rest (2.8 s). Frames advance through the real cels using CSS. Exact prompts, source references and file sizes are recorded in `docs/ui-animation-assets.json`; format-sidecar provenance is included beside each WebP. The animation sheets are fetched only when a real operation outlasts 300 ms. No animation library, audio, selector or game mechanics are added.
