# 句子改写输入页最终需求复核（2026-10-11）

依据：`8.  练习与生词（3）句子改写 1.docx` 全文及内嵌最终设计图。用户已明确所有网页导航均在顶部，仅安装的 Android 手机应用采用底部导航；沿用该约束，不根据示意图恢复网页底部导航。已移除的语言选择器、PDF、旧字体不恢复。

| 文档范围 | 实现/复核 |
| --- | --- |
| §3–5 返回与标题 | 轻量 chevron + 练习与生词返回；米白背景上的“句子改写”与指定副标题，无额外标题卡。英文内容统一现有无衬线字体；阅读页字体不改。 |
| §6 进度 | 紧凑白色圆角卡，标题与实际 `已评估 / 总数`、细 progress、横向数字步骤。完成只取现有 store 的 evaluation，草稿/参考/切题/失败均不计入。未完成显示待完成，当前显示当前，完成使用对勾；当前且已评估保留对勾和已评估文案，另有轻量轮廓与 aria-current 表达所在题。正在请求仍有评估中反馈。 |
| §7–9 单题 | 只渲染当前 RewritePracticeCard，按题目内容身份作 key；顶部题号/总数与改写练习标签。目标词汇浅绿色底、居中 24px 品牌绿粗体；原句直接呈现真实数据并正常换行。保留已有原句译文数据，不引入其他数据。 |
| §10 输入 | 多行 textarea，指定占位文字，柔和浅绿底/圆角/浅边框，深色正常字重输入。未预填新答案；用户已有草稿按原 store 恢复。原来的按文章+题目 ID+题目内容隔离保存机制不变，输入立即持久化，保存失败提示/重试与离开保护保留。 |
| §11–14 操作 | 空白/仅空格时评估禁用，有效文字启用品牌绿；闪光图标、平滑颜色变化、无夸张按钮变形。评估仍调用原服务，原 pending 锁/失败反馈/晚返回保护不变。参考默认收起，展开不填答案、不改完成数；切题统一收起。第一题不显示上一题，其他题目次级居中文字按钮，距主按钮 20px。步骤按钮可自由跳题，无自动评估。 |
| §15–18 导航/适配 | 全站四个导航与练习选中状态保留；网页顶部、安装 Android 底部仍由原 app shell 管理。输入支持 native 光标/粘贴/多行，页面自然纵向滚动，主按钮在正常文流。visualViewport resize/focus 后只在输入超出可见区时安排一次滚动，缩放时不强行滚动，取消未执行帧和监听。页面最大 44rem，所有设备同一单题模式；步骤过多或大字号时可在本模块横向滚动，页面本身无横向溢出。 |
| §19–20 数据边界 | 草稿与评估继续使用既有外部 store；当前题按内容 key 选择而非位置绑定，顺序变化不会混用答案。完全相同题目去重，复用 ID 但内容不同的题目仍各自保留。空集合沿用原空状态。评估成功后的反馈块原样保留，本轮未改算法、接口或结果设计。 |

验证：

- 单元/组件测试 140 项，139 通过、1 跳过、0 失败。包含草稿持久化/隔离、pending 去重、错误恢复与晚返回保护；新增单题初始状态、真评估计数/已评估当前优先状态、题目重复身份测试。
- 独立 QA 阅读身份，不提交 AI 请求；空格+换行按钮禁用，有效多行文字启用。1→3 跳题时新题空白，3→2→1 返回恢复第一题完整草稿；参考切题收起。返回上级、重新进入与刷新均恢复草稿，进度始终为 0/4。
- 390×844 手机、1440×900 桌面检查；桌面页面宽 704px且只有一题。320×568 长多行输入、320×480/24px 根字体、768×1024 大字号均无横向页面溢出，仍只有一个 textarea；大字号主按钮高 78px，可自然滚动到达。
- 实际 localhost 第 2 题使用用户已有 genuine/原句数据，输入为空、按钮禁用、参考收起、上一题可见，四个顶部网页导航保留；实际用户草稿未修改，未评估。截图 `rewrite-input-final.png`。
- TypeScript 检查、生产构建和 diff 空白检查通过；UI detector 无输出。构建保留现有主包 >500kB 提示。

浏览器尺寸与字号模拟不等于真机软键盘验收；Android/iOS 实机键盘、触摸与系统大字号尚未验证。未请求或消耗真实 AI 评估额度。
