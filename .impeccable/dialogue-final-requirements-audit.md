# 对话阅读页复核（2026-10-11）

依据：`4. 阅读页（2）：对话文体阅读界面优化需求文档.docx` 及其中两张参考图。用户要求优先：已移除功能不恢复，网页版导航在顶部，只有安装后的 Android 手机应用使用底部导航。

| 文档范围 | 实现与复核 |
| --- | --- |
| §3–4 信息区与更多菜单 | 复用真实标题、CEFR、词数和现有更多菜单。改写、历史、剧本/段落等继续收纳；新增点击非聚焦背景关闭菜单的处理。未恢复已移除的 PDF。 |
| §5 播放器 | 继续复用唯一主播放器、真实音频事件、角色语音配置及设备降级、可拖动进度。没有复制播放器或硬编码示例时长。设备语音无真实总时长时继续显示文本位置百分比。 |
| §6–7 语言及排版状态 | 原文/全文翻译与剧本/段落独立。剧本默认，切换入口在更多菜单；不重生成、不写文章数据。同一句在两种排版中复用同一标识，首句的角色名称不混入翻译查询，已展开句子可随布局切换保留。 |
| §8–10 连续对话 | 对话正文直接呈现在页面背景上，正文外白框、逐轮白卡、边框和过大内边距已移除。46px 角色栏、36px 头像、12px 栏间距、28px 轮次间距。句子为 inline 连续文本；相邻同角色的独立轮次不合并。长角色名称完整换行。场景说明使用自然正文，不另加白卡。 |
| §9 角色识别 | 根据实际角色名生成首字母，沿用现有稳定角色颜色映射，头像颜色之外保留可读名称。全文译文优先由准确英文原句映射构成，并保留源角色及轮次，不按中文标点猜配。 |
| §11、19 字体 | 复用故事页当前已定稿的 Nunito/Noto Sans 字体与字号、1.65 行高。文档 §11 的衬线说明与其插图及当前全局定稿不一致；依据 §19.4「最终以项目已定稿的全局字体与字号规范为准」及用户不恢复已移除内容的要求，没有恢复旧衬线字体。 |
| §12 生词 | 复用真实精选词汇匹配；词组可整体点击，绿色实线下划线，无文字背景块、无额外加粗。 |
| §13、15 融合翻译 | 只有当前选择的句子转为浅绿色卡，英文、中文、浅色分隔线和关闭按钮在同一卡内。准确原句映射沿用既有逻辑；无翻译时保留原文并使用既有错误/重试处理。关闭恢复连续文本；键盘展开焦点进入关闭按钮，关闭回到原句。 |
| §14 单词弹窗 | 继续复用现有居中 WordDetailModal、遮罩、详情字段、发音、收藏及内部滚动，不插入正文卡。生词 stopPropagation，卡内生词打开弹窗后关闭保留原卡及滚动位置。 |
| §16–17 词汇及练习 | 复用真实精选词汇数量、词汇列表、同一收藏状态和当前文章练习入口，无新评分或存储机制。 |
| §18 导航 | 依用户 2026-10-11 澄清，所有网页使用顶部导航；安装后的 Android 手机底部导航规则不变。没有按文档恢复网页底部导航。 |
| §20–23 状态、响应式、无障碍 | 复用全局动效、减少动态设置、对话角色音频与阅读状态。句子 Enter/Space、单词按钮、共享原生 dialog、音频操作名称保留。正文自然滚动。 |

浏览器验证使用隔离预览和明确的测试文章，未写入用户文章或收藏数据，示例不进入正式页面。覆盖：3 个角色、同一角色相邻两轮、长名称、长单词、词组高亮、逐句展开/收起、卡内词汇弹窗、收藏同步、全文译文身份顺序、菜单布局切换，以及段落模式首句翻译。320×800（根字体 24px）、768×1024、1440×900 均无横向溢出；320px 融合卡右边界 299px。普通故事页保持白色正文容器和同一字体。临时预览完成后删除。
