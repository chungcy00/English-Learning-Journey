# 历史页最终设计验收（2026-10-23）

> 后续文档13已将词汇模式定稿为真实已收录词库的分级复习任务看板；本文词汇模式的“精选词汇关联历史短文”记录为上一轮实现，现以 `history-vocabulary-final-requirements-audit.md` 为准。短文篇数模式及用户明确不新增阅读进度的约束保持。

依据：`12. 历史页（1）：阅读历史记录与 CEFR 数据可视化优化需求文档.docx` 全文及5张内嵌设计图。

## 用户明确的范围覆盖

- 本轮用户确认：**不新增进度系统，本次仅优化现有历史功能**。项目只有当前会话的阅读滚动位置，没有真实百分比或完成状态。因此文档§11.5、§13及对应完成率验收不实施；卡片统一为“阅读”，不虚构未读/继续阅读/再次阅读，不新增“仅看已读完”。App原阅读位置记忆保持，不改阅读正文或播放器。
- 此前用户明确网页桌面/平板/手机导航均在顶部，仅安装后的Android手机应用在底部；文档的底部导航示意不覆盖这一指示。本轮不改全局导航。
- 不恢复主题/正文摘要/历史搜索、语言菜单、PDF、旧字体等删除内容。未改生词本及其他已定稿页面。

## 需求映射

| 文档范围 | 实现与验证 |
| --- | --- |
| §3–5 标题与统计容器 | 单列44rem最大宽度；内容顶部24px及安全区；总篇数来自完整readings，不受筛选影响；白色圆角统计容器。统计说明明确历史短文与selectedVocabulary精选词汇数量，非个人生词本收藏数。 |
| §6 圆环 | 默认无等级选择，中心“总计/N篇/学习短文”；词汇模式单位为条。SVG真实数据扇区，点击/Enter/Space同一回调，再次点击取消。非选中opacity=.2、200ms渐变。零数据只有中性轨道，总计0，无伪扇区。环带40/240比例、390视口实际约48px径向宽，直接命中对应扇区；未扩大相邻扇区的重叠点击范围。极小占比仍可使用完整44px图例/等级按钮。 |
| §7–8 色彩与等级 | cefrVisuals为唯一局部六级颜色定义，扇区/图例/选中边框/提示/HistoryLevelBadge复用。B2为定稿粉紫#B69CAF。浅背景配深色文字，不使用浅主色作小字。六级两列，中文入门/基础/中级/中高级/高级/精通。零数据保留位置和0/0%，弱化且disabled，不允许空筛选。 |
| §9 筛选 | 单一selectedLevel供图表、图例、卡片、历史列表；当前筛选提示在统计区底部，背景随等级变，清除同步。列表标题复用彩色胶囊。不默认选择占比最大等级，不再把并列最高称作唯一主修等级；没有新增重复总数摘要。删掉所选等级最后一篇后立即回到总计、清除过期筛选。 |
| §10 词汇模式 | distributionSource沿用每篇selectedVocabulary里的真实cefrLevel；未知等级独立中性扇区和文字计入总数，不按短文等级推算词汇等级。切维度清筛选、变标题/单位/百分比。原数据有可靠的每篇精选词关联，因此保留按词汇等级筛选所属短文，提示明确“含X精选词汇的历史短文”，绝不把词汇等级误作文章等级。 |
| §11–12 历史卡片 | 最近createdAt降序、源数据不改。完整标题、轻量箭头、彩色等级、中性体裁篇幅、真实日期。普通模式整卡独立覆盖按钮，aria-label“阅读：标题”，没有绿色继续阅读大按钮和可点击删除入口。未知日期和元信息有既有兜底。 |
| §14 删除管理 | 管理/完成切换；管理时无阅读按钮，元信息inert/aria-hidden及高度折叠，只保留标题、日期、轻量图标+删除。窄屏大字号时删除在日期行，标题使用完整宽度。删除先原生dialog确认，初始焦点取消、Esc取消、原焦点恢复。pending用ref锁与disabled防重复，失败保留确认和数据并明确重试；成功回焦完成按钮。空列表禁用管理，但允许退出已经开启的管理模式。 |
| §14.7–9 数据 | App原deleteReading封装于现有Dexie事务，删后读取结果同事务完成，失败回滚避免“已删但刷新失败”的虚假失败。沿用原deleteReading，不扩大删除范围，独立生词本记录保留，原sourceCefrLevel关系维护保留。 |
| §15–18 动效/响应式/无障碍 | 复用已安装motion/react的列表opacity进入/退出、position布局过渡，减少动效时duration=0；不增加缩放弹跳或卡片上浮。管理元信息使用grid行高+透明度200/160ms过渡，删除小幅4px水平进入；全页reduced-motion关闭CSS过渡。自然文流滚动，无内部滚动框，无筛选scrollTo或整页重挂载。所有图表操作有标签、pressed、disabled和键盘支持，状态不单靠颜色。 |
