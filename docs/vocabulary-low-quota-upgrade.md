# 词汇系统与省额度改版

本次在原项目上增量修改，用户 2026-11-09 的后续指令覆盖文档中保留句子改写、手动选择词条类型及四档记忆评分的旧要求。模拟验证与真实服务检查分开记录；发布结果以 Git 提交和部署状态为准。

## 学习流程

- 生成短文时，同一响应返回基本词汇及 `paragraphTranslations`。每个段落或对话轮次对应一条原文和译文；点击段落只切换显示。
- 旧文章优先复用已有段落／逐句译文缓存；缺失时仅在用户点击「一次补充本篇段落译文」后请求一次批量翻译。不会自动补翻。
- 文章和词汇采用浏览器系统语音。对话按角色匹配男女声音；设备缺少对应声音时以音高区分并显示提示。系统语音可用性及实际音质取决于设备，不调用项目的云端语音模型。
- 整篇改写、句子改写练习、AI 评分和自动额外表达目录已退出学习流程；旧数据表保留，相关服务端旧接口返回 410。
- 词汇六栏：例句、派生、词根、词组、英释、用法辨析。首次打开未生成的词条时自动一次生成全部栏目并保存；再次打开、切换、收藏与手动编辑均不调用 AI。支持单栏重新生成，并明确提示替换范围。
- 所有文本操作（含失败回退、格式纠正）共享每个操作最多两次模型尝试；正常成功为一次。每次尝试继续经过原有共享 Redis 额度检查。

## 后续界面修正

- 普通词汇学习与历史词汇学习都使用同一六栏详情组件，不再保留旧版释义／例句／搭配三段式卡片。
- 删除 Again／Hard／Good／Easy 按钮、评分保存、失败重试、间隔提示和评分自动跳卡。仅通过上一张／下一张浏览；历史评分和间隔字段仍保存在数据库与备份中，不因浏览或编辑而改写。
- 仅编辑资料时暂停翻卡导航，避免丢失输入；生成等待不锁住浏览。点击卡片正文或空白可整卡翻转；按钮、栏目、发音、收藏和编辑不触发翻转。长卡片沿网页自然滚动，取消卡内固定高度及嵌套滚动。
- 六栏导航使用现有主题色的不规则手绘高亮，无矩形底色、下划线或分隔线；手机可横向滑动。删除背面翻转提示、重复的「单词 · 已收藏」和详情内部横线，保留外框。
- 删除大块手动生成说明和按钮。缓存缺失时自动请求一次；切换栏目不重复请求，失败保留旧资料并提供明确重试，不循环重试。

## 词汇、收藏及旧数据

- 手动添加词条无需文章来源、无需选择类型；输入后先区分单词和多词表达，六栏生成同时识别 word／phrase／idiom／collocation／phrasal verb，不增加分类请求。先检查重复、预览，可编辑基本资料或六栏，再保存。生成失败不自动创建正式词条；可以手动填写基本资料后保存。
- 新增词条按规范空白、弯引号及词条类型判断重复；保留大小写语义，避免合并 US/us、Polish/polish。旧重复项不会自动删除。
- 完整词条与独立例句／词组分别收藏。移除词条会保留独立收藏，并解除词条关联；单独收藏可编辑、朗读和取消收藏。
- 单词本默认搜索全部已收藏词条，保留翻卡浏览；删除新词／学习中／困难／已掌握的状态筛选、标签、编辑、统计及关联的复习入口；另有独立例句、独立词组三个内容视图。独立素材不加入新的记忆曲线。
- 详细资料按栏目记录 AI／手动来源及更新时间；有意义项的例句和定义关联稳定的义项编号。默认生成保留手动修改，明确确认单栏替换时才替换该栏。
- IndexedDB 从版本 2 增量升级到 3，仅增加 `vocabularyDetails` 和 `savedMaterials`。旧表、主键、历史文章、收藏和复习字段保持。旧词条无需批量生成新栏目。
- `vocabularyDetails` 是同一词条的资料缓存，不是第二套单词本。内容保存仅更新学习资料，不修改学习状态、复习次数、下次复习日期和间隔。
- 完整 JSON 备份包含旧数据、词汇资料缓存和独立收藏。还原前先验证，在事务内合并；同编号以备份内容为准。浏览器本地数据不会自动跨设备同步。

## 派生与构词拆解修正

- 派生新增词族基本词与真实派生关系，按词族分组显示英文、词性、中文含义与系统朗读；校验排除原词、词形变化和重复项，不补造稀有或相似词。
- 词根新增可选的结构化构词资料：核心词根、中文含义、按原词拼写排列的前缀／词根／后缀、含义组合说明、单独标明的记忆联想及同根词。词根用现有主题中的棕色突出，词缀沿用森林绿。校验要求拆解拼回原词且包含词根；词源事实的可靠性仍由生成规则约束，不能把结构校验当作词源权威认证。
- 新字段为可选，旧缓存文字照常显示；不根据表面拼写自动推断构词，也不自动重生成已缓存资料。需要更新旧分析时，仅重新生成对应栏目。手动编辑支持词族关系、各构词部分、联想及同根词；单栏重生成不改其他四栏。
- plural、third person、past、participle 等旧英文词形标签在显示和编辑时本地转为中文，新生成也要求中文标签。英文词形本身不变，不消耗额外生成额度。
- 验证包括旧结构兼容、新结构校验、错误拆解拒绝、派生去重、结构化编辑保留、其他四栏不被覆盖，以及桌面／390px 手机布局（使用固定示例资料，非真实模型生成）。

## 词组与用法辨析修正

- 词组按学习词典常见表达的方向生成，保留冠词、介词和句型结构。通常以 4–8 项为参考、最多 10 项，但数量服从真实学习价值，不按类别凑数。简洁卡片突出英文和简体中文含义，不重复分类标签，继续支持系统朗读与独立收藏。
- 用法辨析新增可选类型及纠错对照结构：场景、句型、近义辨析、确有错误的纠正、语体和自然表达。以中文标题和实质说明为主，按需配英文例句与译文；不把读音、释义重复或简单搭配列表作为主要内容。不为每个单词强制覆盖所有方向；语体偏好不得标为语法错误。
- 编辑器支持完整词组、分析标题、中文解释、例句，以及需要时的误用／正确表达；旧文本格式与已有独立收藏保持兼容。只重新生成本栏，其他栏目、人工修改与独立收藏保持原有保护规则。例句和英释的生成与展示保持原样。

- 后续主导航新增「单词」，打开独立的自定义词条页，默认展开添加表单并显示手动添加的词条；原文章词汇添加和单词本保留全部功能。两页共用词汇数据库、去重和六栏缓存；浏览器与安装版导航均有此入口，手机使用简短标签。删除词条详情底部「已加入生词本」及独立收藏保留的重复说明文字，保留移出操作与原有数据保留规则。

- 真实生成检查发现轻量模型仍可能给出生硬词组或把读音当作语法；完整六栏采用现有轻量模型并显式设置低强度推理，保持一次请求、缓存和最多两次模型尝试的额度保护；未采用实测在现有 45 秒时限内持续超时的完整 Flash 配置。返回校验额外过滤误标成语法的发音／重音标题，不覆盖旧缓存。

## 派生／词根再次验收

- 浏览器中旧 `conflict` 仍缓存「Latin confligere」等简短词源，以及没有词族关系的 `conflicting`。兼容缓存不代表它们已升级为新结构；现在两栏会提示资料尚缺词族关系或构词拆解，由用户选择编辑或仅重新生成本栏，不自动重做其他四栏。
- 新响应的构词说明、记忆联想和派生关系明确要求简体中文，并保留真实构词中间步骤；不会把 `helpful + -ly` 错教为一个未经解释的简单 `-fully` 后缀。同根词列表去除原词自身和重复词。
- 单栏重新生成会一并提供已缓存的词形变化，服务端排除这些形式，避免因本次响应省略词形表而把已有现在分词再次算成派生词。单栏更新仍保留另外四栏、收藏与复习记录。

- 四栏联合验收继续保留例句与英释：词组新增简体中文解释约束并去除完全重复的表达，仍保留冠词、介词、系统朗读与独立收藏；用法辨析会过滤误标为语法的英文 stress-change 标题，旧版缺少分析类型时明确提示可更新，不自动重写旧资料。介词解释要求对应完整句法结构，不臆造按抽象／具体划分的选择规则。
- 派生的常见性标准明确为通用学习词汇；不能仅因某个偶见的否定分词或专门术语构词上成立，就为填充列表而收录。
