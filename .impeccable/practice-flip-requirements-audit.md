# 复习卡翻转需求复核（2026-10-11）

依据：`7.  练习与生词（2）：复习卡翻转.docx` 全文与内嵌最终图。仅修改复习卡及相关展示/交互。已移除的语言选择器、PDF 等保持移除，所有网页导航仍在上方。

| 文档范围 | 实现 |
| --- | --- |
| §3–5、§10 正反面 | 复用 VocabularyHeader：词条、可用音标、词性独立行，字体、相对位置和发音按钮完全相同。无音标不占位。白色圆角容器，数字翻页与正面轻量提示保留。沿用原三维翻转、单面可访问与减少动态效果。 |
| §6 释义 | 中文释义、英英释义、例句标签正常字重，无冒号。中文释义突出且不截断；英文自然换行。例句浅绿圆角、无边框/阴影，显示原始例句不额外添加装饰引号；实际例句中的语义引号保留。已有例句译文继续显示。搭配折叠标题+箭头，展开真实字符串列表、细分隔线，没有绿色搭配卡。未虚构缺失译文。 |
| §7 评分 | 卡内底部四按钮，无常驻边框与上方贯穿线，复用低饱和主题色。名称与间隔两行相隔 3px。调度持久化与展示共用 reviewDelayMs；原 days 算法与原 Again 30 分钟规则不变。原保存锁、成功换词/完成、失败保留词条与重试原样保留。 |
| §8–9 滚动 | 头部与评分不脱离卡片，仅中间内容 overflow-y:auto。根据 visualViewport/窗口高度、真实导航高度、留白与安全区域计算上限。ResizeObserver 监测头尾/导航，当中部可用空间不足 120px，降级为整卡自然布局、页面滚动。边界线只由中间 scrollTop>0 触发，顶部不显示；卡片翻面/换词销毁旧中间滚动节点，清理未结束滚动、搭配状态和边界线。 |
| §10、§13 事件/可访问性 | 背面中间和底部标记 data-flip-ignore，所有内部控件保持原动作；选择文本不翻面，鼠标双击后续 click 不重复翻转。头部是背面指针翻转区域，Enter/Space 可翻面；可滚动区域有标签且可键盘聚焦。沿用 44px 发音、56px 评分按钮与全站可见焦点。局部滚动不截断页面滚动链。 |
| §11–12 数据/适配 | 复用真实 VocabularyItem 字段、当前文章收藏范围、数字翻页、索引/会话持久化；数据库结构不变。复习卡最大 32rem，窄屏评分必要时两列，长词条换行。未修改改写、生词本、导航布局。 |

验证：

- 隔离组件验收页不接用户存储：390×844 正反面词条顶部偏移均为 97px，字号/字体/字重一致。展开搭配、调用发音后仍为背面；长内容区域能滚动，底部仍在卡内，滚动后出现边界线。
- 浏览器键盘 End 的尚未结束滚动在翻面时会继续，初次检查发现这一问题；通过重建中间节点修复后，反复翻面 scrollTop=0、边界线=false、搭配展开=false。
- 320×568 短屏和 320×480、24px 根字体长内容场景无横向溢出；大字号极短屏使用自然布局。768×1024、1440×900 检查宽度 510px（包含内外边框差异），正常内容自然布局，无横向溢出。四列按钮在正常尺寸、窄屏必要时两列。
- 实际 localhost 页面使用用户已有 considerate 词条，确认 1/5、真实释义/例句/三个搭配，评分在卡内；未点击真实评分，未修改收藏/数据库。截图：`practice-flip-final.png`。
- npm run lint、生产构建、git diff --check 通过；137 项测试，136 通过、1 跳过、0 失败。新增正反面语义结构/缺失音标/引用文本测试，以及展示间隔与调度毫秒对齐测试（包含 10.5 天）。UI detector 无输出。
- 构建仍有已有主包 >500kB 提示。Android/iOS 真机滚动与发音音质未实机验收；组件验收中的发音调用由隔离回调计数验证，真实设备声音能力沿用现有 speech 工具。
