# 单词详情居中弹窗复核（2026-10-11）

依据：`5. 阅读页（3）：单词详情居中悬浮弹窗优化需求文档.docx` 及内嵌两张设计图。继续遵循用户要求：不恢复已移除功能；所有网页版导航在顶部，安装后的 Android 手机应用导航在底部。本轮仅调整阅读场景的共享词汇弹窗和必要的收藏、关闭交互，不重做正文、播放器、翻译服务、生词本独立页或复习算法。

| 文档范围 | 实现与复核 |
| --- | --- |
| §3–4 居中容器 | 白色、24px 四周圆角、16px 左右留白、480px 最大宽度、柔和阴影。默认最大 75dvh，内容短时自然缩短；低高度视口按 §11.2 调整可用高度与标题留白，考虑安全区域。没有拖拽条、双高度或抽屉定位。 |
| §5–6 固定头部 | 单词标题旁的真实发音按钮、右上角关闭按钮，下一行展示真实音标、词性和词汇类型。长词组可换行，头部与滚动正文间有极浅分隔线。 |
| §7 学习内容 | 保留现有中文释义、英英释义、真实例句与关联翻译、搭配。例句不额外添加装饰引号，原有语义引号保留；搭配纯展示、自动换行且不横向溢出。当前应用已移除其他释义语言选择，不恢复语言控件。 |
| §8 收藏 | 未收藏时绿色加入按钮；已收藏时左侧确认状态和右侧透明次级“移出”。弹窗内移出调用现有取消收藏存储，不叠加删除确认弹窗；移出成功后提供 5 秒撤销，保持弹窗打开。撤销恢复原始保存记录，包括复习间隔、次数、时间与文章关联。其他生词本页面原有删除流程保留。 |
| §8.6 异步结果 | 即时请求锁与禁用状态防重复提交；等待存储成功才更新收藏数据。错误明确显示，保持原状态；失败不消耗撤销快照。旧单词操作的晚到反馈不覆盖新单词。添加已存在于其他文章的表达只关联当前文章，不误删原记录或重置复习进度。 |
| §9 内部滚动 | 中部 overflow-y:auto、min-height:0、overscroll-behavior:contain、pan-y 和原生触摸滚动。头尾不随正文滚动；固定背景并保存、恢复阅读位置。重开或换词从详情顶部开始，收藏变化不重置滚动位置。 |
| §9 关闭 | 右上角、外部遮罩、Escape、浏览器/系统 Back。临时同 URL 历史条目让 Back 优先关闭弹窗，正常关闭仅消费自身条目；保留原阅读位置和触发焦点。无遮罩点击穿透。 |
| §10 全屏遮罩与动效 | 原生 modal dialog 在顶层使背景不可操作，70% 白色遮罩和 12px 模糊覆盖正文及导航。弹窗清晰，沿用全局淡入淡出与减少动态设置。未恢复网页底部导航。 |
| §11–13 适配与无障碍 | 手机、横屏、平板、桌面均居中，低高度大字体适度压缩标题和留白；横屏撤销提示暂时复用收藏操作区，避免中部被挤空。按钮有操作名称、焦点可见，正文可选择复制，内容区可键盘和滚轮滚动。 |

浏览器验收使用隔离测试页面，不写入用户数据：

- 487×960 短内容弹窗：左 16px、宽 455px、高约 617px，垂直居中；遮罩 rgba(255,255,255,.7)、blur(12px)；移出按钮透明背景。
- 320×480、24px 根字号、长词组与长详情：弹窗顶部 16px、底部 464px，中部可用高度 160px，底部操作在卡内。
- 768×320、24px 根字号：顶部 16px、底部 304px，中部可用高度 72px；平板 768×1024 和桌面 1440×900 长内容弹窗分别限定为 768px 和 675px。页面无横向溢出。
- 真实滚轮滚动到最后内容：scrollTop 1421px 等于最大值，最后一行在操作栏上方，头部、弹窗和底部栏位置不变。背景维持锁定。
- 阅读中部打开后 Back 关闭：恢复 scrollY 352px 和原触发按钮，保持同一页面；重开词条 scrollTop 0。
- 模拟首次收藏存储失败：双击仅 1 次请求，已收藏状态保留并显示失败；重试移出、撤销恢复成功，总计 3 次请求。底部导航点击位置上的遮罩关闭不会切换导航。
- 点击真实设备发音入口无错误提示；未把此观察写成声音质量验收通过。

类型检查、构建通过；128 项测试通过、1 项跳过。新增测试覆盖完整词条与复习安排恢复、存储失败状态、跨文章词条关联、返回关闭及正常关闭历史清理。
